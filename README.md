# lecture-holistic-explainer-skill

**语言：简体中文 | [English](./README_EN.md)**

一个面向不同专业课程的 Codex Skill，用中文把 PDF 课件、讲义和教学幻灯片重组为完整、连贯、易懂的整体课程讲解。

它不会机械地逐页翻译，而是重建课件的知识主线，把动机、概念、关系、推理、证据、公式、图示、算法、系统、案例和习题串成一套可以独立阅读的讲解。虽然最终内容按逻辑组织，但每个知识点仍然保留来源页码，并覆盖要求范围内的全部课件内容。

本项目是从 `lecture-synthesis-explainer` 独立复制并扩展出来的新 Skill，不会替换或修改原 Skill。

## 模型推荐

推荐使用 GPT 系列模型，适配效果较好。

不同 GPT 模型在长上下文、公式识别、图表理解、代码分析和视觉检查方面可能存在能力差异。对于页数很多、公式或代码密集、图示依赖较强的课件，建议使用支持文件与图像理解的 GPT 模型，并按主题拆分讲解。

## 两个语言版本

### 中文版

- Skill 名称：`lecture-holistic-explainer`
- 调用方式：`$lecture-holistic-explainer`
- 仓库位置：根目录的 `SKILL.md` 和 `agents/openai.yaml`
- 默认输出：中文

### 英文版

- Skill 名称：`lecture-holistic-explainer-en`
- 调用方式：`$lecture-holistic-explainer-en`
- 仓库位置：[`english/`](./english/)
- 默认输出：英文
- 语言处理：非英文课件内容翻译成英文，英文原文按需保留

英文项目说明请查看 [English README](./README_EN.md)。

## 核心能力

- 重建整套课件的整体知识主线，而不是逐页机械复述
- 覆盖要求范围内的所有知识点、公式、图表、来源、算法、证明、案例、动画变化、例子和习题
- 为每个讲解项目保留来源页码
- 先讲清核心思想、动机和关系，再展开必要细节
- 形成足以基本替代阅读原课件的自包含讲解
- 根据课件实际内容选择专业讲解策略，一套课件可以混合多种策略
- 对重复页和动画递进内容去重，同时保留新增内容与完整页码
- 对文本提取不足、公式损坏或视觉内容密集的页面进行渲染和视觉检查
- 默认在聊天中回答；用户要求讲义、Word、Markdown 或 PDF 时再创建文件

## 跨专业适配

### 形式化、理论或数学内容

适用于数学、统计、自然科学、工程理论、定量经济学和逻辑等内容。重点解释定义、符号、单位、假设、边界条件、定理直觉、证明策略、公式推导、参数变化和变式应用。

### 实验、实证或数据内容

适用于实验科学、生命与健康科学、心理学、教育学和社会研究等内容。重点解释研究问题、变量、对照、样本、测量方法、实验设计、图表、不确定性、偏差，以及观察、结果、解释和因果结论之间的区别。

### 机制、流程或工程内容

适用于物理、化学、生物、环境、医学、工程和组织机制等内容。重点解释组成部分、输入输出、阶段顺序、状态变化、反馈关系、约束、边界条件、因果链和失效点。

### 概念、论证、历史或文本内容

适用于人文、法律、哲学、历史、语言和定性社会科学等内容。重点解释核心概念、论题、前提、证据、反方意见、限定条件、结论、时间线、历史语境、来源类型、作者立场和不同解释。

### 案例、应用、程序或创作内容

适用于商业、经济、法律、医学、设计、艺术、语言学习和实验操作等内容。重点解释情境、目标、利益相关者、约束、判断标准、分析方法、操作步骤、替代方案、风险、结果和评价标准。

## 保留计算机专业的原生深度

跨专业改造不会把计算机课程压缩成泛化的“流程讲解”。新 Skill 为计算机内容保留了两套独立策略。

### 算法与数据结构

完整讲解问题模型、输入输出、目标与约束、基线方法、关键洞见、数据结构、状态定义、不变量、递推关系、伪代码、计算顺序、终止条件、边界情况、小例子追踪、正确性证明、时间与空间复杂度、归约、近似保证、随机化假设和摊还分析。

### 计算系统与软件

完整讲解系统目标、抽象边界、架构、组件、模块、层次、接口、职责划分、数据流、控制流、状态转移、协议、时序、并发、同步、生命周期、内存、存储、网络、编译、执行、一致性、事务、查询、安全、性能、资源成本、可靠性、设计权衡和失效模式。

适用课程包括操作系统、计算机网络、数据库、计算机体系结构、软件工程、机器学习、编译原理、安全、分布式系统、程序设计语言、图形学、信息论和 AI 系统。机器学习与数据科学内容会根据需要同时使用数学、算法、系统和实证策略。

## 如何使用

调用中文版并提供课件文件，例如：

- `请用 $lecture-holistic-explainer 完整讲解这份生物学课件，把实验、机制和图表串起来，并保留页码。`
- `请整体讲清这份经济学课件的模型、假设、公式、证据和结论，不要逐页翻译。`
- `请把这份历史课件重组为一套连贯讲解，说明时间线、观点、史料来源和争议。`
- `请完整讲解这份操作系统课件，保留架构、状态转移、并发规则、性能权衡和页码。`
- `请讲清这份动态规划课件的知识主线，包括状态定义、转移、不变量、正确性和复杂度。`

如果用户只说“解释这份课件”而没有说明讲解模式，Skill 会区分：

- 整体讲解：按概念和逻辑重组内容，同时保留完整覆盖和页码
- 逐页讲解：严格按照每一页的顺序和内容对应解释

## 工作方式

1. 确认文件、页数、范围、输出语言和讲解模式。
2. 提取文本，并渲染检查公式、图表、地图、时间线、代码、动画或布局重要的页面。
3. 建立覆盖清单和课件知识地图，记录全部知识点、推理材料及其页码。
4. 判断课件需要哪些专业策略，并按知识逻辑组织讲解。
5. 对公式、实验、算法、系统、论证、案例和视觉材料使用对应的深度标准。
6. 完成前逐项核对覆盖清单，确保没有漏掉内容或页码。
7. 如果生成文件，渲染并检查中文、公式、图片、分页和版面。
